# Co-Authored-By 功能实现总结

## 需求概述

在提交消息生成的地方，当选择的追加类型是 `Co-Authored-By` 时，支持选择预定义的 AI 助手列表或自定义输入，生成格式化的 Co-Authored-By 行，多个用分号分隔。

## 实现方案

### 新增文件

#### 1. CoAuthoredByDialog.kt
**路径**：`src/main/kotlin/com/examplecn/action/CoAuthoredByDialog.kt`

**功能**：专门的 Co-Authored-By 选择对话框

**主要特性**：
- 左侧预定义 AI 助手列表（10个）：
  - Claude Code <claude-code@anthropic.com>
  - Cursor <cursor@cursor.sh>
  - Yonwork <Yonwork@yonyou.com>
  - OPENAI <openai@openai.com>
  - GitHub Copilot <copilot@github.com>
  - CodeBuddy <codebuddy@ai-assistant.com>
  - Lingma <lingma@alibaba.com>
  - Trae <trae@trae.ai>
  - DeepSeek <deepseek@deepseek.ai>
  - GLM <glm@glm.com>

- 支持多选（`ListSelectionModel.MULTIPLE_INTERVAL_SELECTION`）
- 右侧显示已选择的作者列表
- 底部自定义输入区域（名称 + 邮箱）
- 基于邮箱去重（`AuthorInfo` 使用 `email` 作为 `equals`/`hashCode` 依据）
- 输入验证（至少选择一个作者，自定义输入不能为空）

**核心方法**：
- `createCenterPanel()`：构建 UI 布局
- `getFormattedCoAuthoredBy()`：返回格式化的 Co-Authored-By 字符串（分号分隔）
- `doOKAction()`：确认前验证

**数据结构**：
```kotlin
data class AuthorInfo(val name: String, val email: String) {
    fun formatCoAuthoredBy(): String = "Co-Authored-By: $name <$email>"
    override fun equals(other: Any?): Boolean = email == (other as? AuthorInfo)?.email
    override fun hashCode(): Int = email.hashCode()
}
```

## 技术亮点

### 1. 基于邮箱的智能去重
使用 `Set<AuthorInfo>` 存储已选择的作者，通过重写 `equals()` 和 `hashCode()` 方法，基于邮箱地址去重，避免重复添加相同的作者。

### 2. 多选支持
左侧预定义列表支持 Ctrl/Cmd + 点击进行多选，一次可以添加多个作者，提高操作效率。

### 3. 实时预览
右侧"已选择"列表实时显示格式化后的 Co-Authored-By 行，用户可以直观看到最终追加到提交信息中的内容。

### 4. 输入验证
- 确认前验证至少选择一个作者
- 自定义输入时验证名称和邮箱不能为空
- 提供友好的错误提示

### 5. 分号分隔
多个作者之间使用分号（`;`）分隔，符合 Git 提交消息约定，便于后续解析。

1. **简化操作流程**：用户不需要手动输入复杂的 Co-Authored-By 格式，只需从列表中选择或简单输入名称和邮箱

3. **提高效率**：预定义常用 AI 助手，一键添加，支持多选批量添加
