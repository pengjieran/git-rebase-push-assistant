# Co-Authored-By 功能测试清单

## 测试环境
- IntelliJ IDEA 2025.3.5
- 插件版本：1.0.5

## 功能测试项

### 1. 基本功能测试

#### 1.1 打开 Co-Authored-By 对话框
- [ ] 在 Git 提交界面，点击"变基并提交推送"按钮
- [ ] 在对话框的提交信息区域下方，找到"自动追加"工具栏
- [ ] 从下拉框中选择"Co-Authored-By"
- [ ] 点击"追加"按钮
- [ ] **预期结果**：弹出"选择 Co-Authored-By"对话框

#### 1.2 查看预定义列表
- [ ] 左侧应显示"预定义AI助手："标签
- [ ] 列表中应包含 10 个 AI 助手：
  - Claude Code
  - Cursor
  - Yonwork
  - OPENAI
  - GitHub Copilot
  - CodeBuddy
  - Lingma
  - Trae
  - DeepSeek
  - GLM

### 2. 选择功能测试

#### 2.1 单选预定义作者
- [ ] 在左侧列表中选择"Claude Code"
- [ ] 点击"添加选中 →"按钮
- [ ] **预期结果**：右侧"已选择"列表中显示 `Co-Authored-By: Claude Code <claude-code@anthropic.com>`

#### 2.2 多选预定义作者
- [ ] 在左侧列表中按住 Ctrl/Cmd 键，选择多个 AI 助手（如 Cursor、GitHub Copilot、DeepSeek）
- [ ] 点击"添加选中 →"按钮
- [ ] **预期结果**：右侧列表中显示所有选中的作者，每个一行

#### 2.3 去重功能
- [ ] 选择已添加过的"Claude Code"
- [ ] 再次点击"添加选中 →"按钮
- [ ] **预期结果**：右侧列表中只显示一次"Claude Code"，不会重复添加

#### 2.4 移除已选择的作者
- [ ] 在右侧"已选择"列表中选择一个作者
- [ ] 点击"移除选中"按钮
- [ ] **预期结果**：该作者从列表中移除

### 3. 自定义输入测试

#### 3.1 添加自定义作者（正常流程）
- [ ] 在"自定义输入"区域，名称输入框中输入"Test User"
- [ ] 邮箱输入框中输入"test@example.com"
- [ ] 点击"添加自定义"按钮
- [ ] **预期结果**：
  - 右侧列表中显示 `Co-Authored-By: Test User <test@example.com>`
  - 输入框自动清空

#### 3.2 空输入验证
- [ ] 名称或邮箱留空
- [ ] 点击"添加自定义"按钮
- [ ] **预期结果**：弹出警告对话框"请输入名称和邮箱"

#### 3.3 自定义作者去重
- [ ] 添加一个自定义作者（如 "User1 <user1@test.com>"）
- [ ] 再次输入相同的邮箱 "user1@test.com"（名称可以不同）
- [ ] 点击"添加自定义"按钮
- [ ] **预期结果**：不会重复添加（基于邮箱去重）

### 4. 确认和取消测试

#### 4.1 未选择任何作者时点击 OK
- [ ] 不选择任何作者（或移除所有已选择的）
- [ ] 点击"OK"按钮
- [ ] **预期结果**：弹出警告对话框"请至少选择一个作者"

#### 4.2 正常确认流程
- [ ] 选择至少一个作者
- [ ] 点击"OK"按钮
- [ ] **预期结果**：
  - 对话框关闭
  - 选中的作者追加到提交信息末尾
  - 格式为：`Co-Authored-By: Name1 <email1>;Co-Authored-By: Name2 <email2>`

#### 4.3 取消操作
- [ ] 选择一些作者
- [ ] 点击"Cancel"按钮
- [ ] **预期结果**：
  - 对话框关闭
  - 提交信息不变

### 5. 格式输出测试

#### 5.1 单个作者输出
- [ ] 选择 1 个作者并确认
- [ ] **预期结果**：提交信息末尾追加 `Co-Authored-By: Name <email>`

#### 5.2 多个作者输出（用分号分隔）
- [ ] 选择 3 个作者并确认
- [ ] **预期结果**：提交信息末尾追加：
  ```
  Co-Authored-By: Name1 <email1>;Co-Authored-By: Name2 <email2>;Co-Authored-By: Name3 <email3>
  ```

#### 5.3 提交信息非空时的追加
- [ ] 在提交信息框中输入一些文本（如 "feat: 新功能"）
- [ ] 选择作者并确认
- [ ] **预期结果**：
  - 如果原文本不以分号或换行结尾，自动添加分号分隔
  - 格式为：`feat: 新功能;Co-Authored-By: Name <email>`

### 6. UI 交互测试

#### 6.1 对话框大小
- [ ] **预期结果**：对话框大小合适（600x450），内容完整显示

#### 6.2 列表滚动
- [ ] 选择多个作者（超过可见区域）
- [ ] **预期结果**：列表支持滚动查看所有内容

#### 6.3 焦点和键盘导航
- [ ] 使用 Tab 键在各个输入框和列表之间切换
- [ ] 使用方向键在列表中导航
- [ ] **预期结果**：焦点切换正常，键盘操作流畅

### 7. 集成测试

#### 7.1 完整提交流程
- [ ] 打开 Git 变基推送对话框
- [ ] 输入提交信息
- [ ] 添加 Co-Authored-By 信息
- [ ] 选择目标分支
- [ ] 点击"确定"执行提交
- [ ] **预期结果**：
  - 提交成功
  - 提交信息中包含 Co-Authored-By 信息
  - 可以在 Git 历史中查看完整的提交信息
